# Kotonoha - 言の葉 🍃

A minimalist, client-side diary application tailored for Japanese language study. 

## Goal
To provide a distraction-free, beautifully designed space to practice writing daily entries in Japanese, mark vocabulary words for review, and keep track of study notes.

## Features
- **Bilingual Entries**: Write in Japanese with optional English translations and notes.
- **Date Editing**: Easily adjust the date for previous journal entries.
- **Vocabulary Highlighting**: Easily mark words using simple `[word]` syntax to highlight them visually in your text.
- **Custom Typography**: Choose between classic Mincho, modern Gothic, Rounded, or Handwriting fonts specifically optimized for Japanese.
- **Privacy First**: All data is securely stored locally in your browser.
- **Import/Export**: Safely backup and restore your diary entries using JSON files.
- **Search**: Instantly filter past entries using English or Japanese text.

## Tech Stack
- React 19
- TypeScript
- Vite
- Tailwind CSS (v4)
- Motion (Framer Motion)
- Lucide Icons
